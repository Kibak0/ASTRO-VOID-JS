# 🚀 ASTRO VOID

**ASTRO VOID** is a 2D infinite runner set in space. Control a spaceship, dodge incoming asteroids, and survive as long as possible while the game progressively gets faster.

The goal is simple: **survive, score points, and beat your high score.**

## 🎮 Features

* 🚀 Infinite space runner
* ☄️ Randomly generated asteroids
* 📈 Increasing speed and difficulty
* 🏆 High-score system saved with `localStorage`
* 🎚️ Adjustable movement sensitivity
* 🎵 Background music and sound effects
* 💥 Game Over system
* 🖥️ HTML5 Canvas rendering

## 🕹️ Controls

| Key       | Action    |
| --------- | --------- |
| `W` / `↑` | Move up   |
| `S` / `↓` | Move down |

Adjust the **Sensitivity** slider from the main menu to change the spaceship's movement speed.

## 🎯 Gameplay

Avoid the incoming asteroids for as long as possible.

Every asteroid successfully avoided awards **10 points**. As the game progresses, the speed increases, making each run more challenging.

Your highest score is automatically saved in your browser.

## ▶️ Run Locally

No installation or dependencies are required.

1. Clone or download the repository.
2. Open the project with a local web server.
3. Open `index.html` in your browser.
4. Select **Nouvelle Partie**.
5. Dodge the asteroids and beat your high score.
